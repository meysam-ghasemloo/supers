# 🛒 سوپرسه‌مارکت (SuperSeMarket)
> **فروشگاه آنلاین تخصصی ارسال مواد غذایی، خشکبار و سوغات اصیل ایرانی به سراسر اروپا**

---

## 🌟 معرفی پروژه
سوپرسه‌مارکت یک فروشگاه مدرن، فوق‌العاده سریع و واکنش‌گرا (Responsive) است که با هدف رساندن طعم اصیل و نوستالژیک ایران به دست هم‌وطنان مقیم اروپا طراحی شده است. این رابط کاربری با تمرکز بر تجربه کاربری سطح یک (UX Pro Max)، انیمیشن‌های مینیمال و ارگونومیک، پالت رنگی هماهنگ (سبز زمردی اصیل ایرانی و طلای زعفرانی) و بالاترین استانداردهای وب پیاده‌سازی شده است.

---

## ✨ ویژگی‌های کلیدی
- **🎨 پالت رنگی هویت بصری اصیل:**
  - رنگ سبز زمردی پرشین (`#064e3b` / `#047857`)
  - رنگ طلای زعفرانی ایرانی (`#f59e0b` / `#d97706`)
  - رنگ زرشکی حراج و تخفیف ویژه (`#881337`)
- **📌 منوی استیکی هوشمند پرفروش‌ترین‌ها:**
  - پین شدن نرم در بالای صفحه هنگام اسکرول
  - تغییر استایل خودکار به نوار شناور اختصاصی زمردی-زعفرانی
  - اسکرول افقی روان دسته‌بندی‌ها روی موبایل و دسکتاپ
- **🎬 انیمیشن اختصاصی دکمه افزودن به سبد خرید:**
  - انیمیشن داخلی تعاملی دکمه با تبدیل آیکون به چرخ‌دستی/لودینگ و ثبت موفق (`اضافه شد ✓`) با مکث ارگونومیک برای بازخورد دیداری شفاف
- **📦 محاسبه‌گر هوشمند هزینه ارسال پست و تحویل:**
  - کارت جمع‌بندی مدرن با استایل مرز خط‌چین (Dashed border) و محاسبه لحظه‌ای زمان تحویل و هزینه به یورو
- **📱 کاملاً واکنش‌گرا (Mobile-First):**
  - تست و بهینه‌سازی دقیق در ویوپورت‌های دسکتاپ (1440px)، تبلت (768px) و موبایل (360px - 390px)
  - بدون هرگونه شیفت یا اسکرول افقی ناخواسته
- **⚡ عملکرد فوق‌العاده سبک و بدون وابستگی:**
  - ساخته‌شده با Pure HTML5, CSS3 و Vanilla JavaScript
  - بدون نیاز به npm install یا سرورهای سنگین backend برای رندر و تست

## 🚀 نحوه اجرای محلی (Local Preview)
به دلیل پیاده‌سازی سبک، برای مشاهده سایت نیازی به نصب هیچ نرم‌افزار خاصی نیست:
1. پروژه را با دستور زیر کلون یا دانلود کنید:
   ```bash
   git clone https://github.com/USERNAME/supersemarket.git
   cd supersemarket
   ```
2. فایل `index.html` را مستقیماً در مرورگر باز کنید، یا با اکستنشن **Live Server** در VS Code اجرا نمایید.

---

## 🌐 انتشار آنلاین در GitHub Pages
برای اینکه همکاران و کاربران بتوانند وب‌سایت را به صورت آنلاین و در مرورگر خود بدون نصب نرم‌افزار مشاهده کنند:
1. در مخزن گیت‌هاب به تب **Settings** بروید.
2. از منوی سمت چپ بخش **Pages** را انتخاب کنید.
3. در قسمت **Build and deployment > Branch**:
   - شاخه: `main`
   - پوشه: `/ (root)`
4. روی **Save** کلیک کنید. پس از ۱ تا ۲ دقیقه آدرس وب‌سایت آنلاین شما به شکل زیر در دسترس خواهد بود:
   ```
   https://USERNAME.github.io/supersemarket/
   ```
